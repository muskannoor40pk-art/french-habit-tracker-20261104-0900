### Overview
Habit Tracker is a lightweight, high-performance web application built to help users across West & Central Africa and Europe build lasting habits. Whether you are tracking daily water intake, study hours, or fitness goals, this tool provides a clean, distraction-free interface to visualize your progress through a weekly grid and streak counters.

### Features
*   **Weekly Habit Grid:** Visualize your consistency at a glance.
*   **Streak Counter:** Stay motivated by tracking your current and best streaks.
*   **Dynamic Management:** Easily add or remove habits as your goals evolve.
*   **Local Persistence:** Your data stays on your device using `localStorage`—no login or database required.
*   **Responsive Design:** Optimized for both mobile devices in diverse network conditions and desktop environments.

### Localization & Accessibility
This project is tailored for an international audience, specifically targeting Francophone regions in West & Central Africa and Europe.
*   **Language:** The interface is localized in French.
*   **Formatting:** Date and numerical formats follow standard European/International conventions.
*   **Directionality:** Optimized for LTR (Left-to-Right) layouts.
*   **Performance:** Designed as a single-file architecture to ensure fast loading times even on slower internet connections.

### Tech Stack
*   **Frontend:** Vanilla JavaScript (ES6+), HTML5, Modern CSS (Grid & Flexbox).
*   **Persistence:** Browser `localStorage`.
*   **Hosting:** GitHub Pages.

### Getting Started
No build step or complex environment setup is required.
